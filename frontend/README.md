# WatchList — front-end

React 19 + Vite. Install, run and environment are documented once, in the
[repository README](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # Vitest
npm run lint    # oxlint
```

It expects the API at `http://localhost:8000`; set `VITE_API_URL` in `frontend/.env` to point
somewhere else.
